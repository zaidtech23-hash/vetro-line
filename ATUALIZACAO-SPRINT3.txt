2. No VS Code abre: database/upgrade-sprint3.sql
3. Copia TUDO, cola no Supabase, RUN
⚠️ Esse SQL não apaga teus dados! Só adiciona coisas novas.


PASSO 2 — SUBSTITUIR A PASTA
────────────────────────────
1. APAGA a pasta vetroline antiga
2. EXTRAI o zip novo (vetroline-sprint3.zip)
3. Pasta vai chamar "vetroline-v3" — RENOMEIA pra "vetroline"
4. Abre no VS Code

────────────────

COMO TESTAR ORÇAMENTO RÁPIDO (FUNCIONÁRIO):
────────────────────────────────────────────
1. Loga como funcionário
2. Abre uma OS
3. Rola até "💰 Orçamento na casa do cliente"
4. Clica em "⚡ Fazer Orçamento Rápido"
5. Coloca valor materiais, mão de obra, desconto
6. O TOTAL aparece automático
7. Clica "Enviar pro Chefe"
8. SAI e LOGA como chefe
9. Vai em ⚡ Orçamentos → o orçamento criado tá lá!


COMO TESTAR CORTES:
───────────────────
1. Como CHEFE, vai em 📋 Ordens
2. Clica no ✂️ ao lado de uma OS
3. Adiciona alguns cortes (ex: Perfil Suprema, Branco, 2.50m, 3 unidades)
4. Salva
5. SAI e LOGA como funcionário
6. Abre essa mesma OS
7. Vai aparecer a lista de cortes
8. Marca os checkboxes quando ele cortou
