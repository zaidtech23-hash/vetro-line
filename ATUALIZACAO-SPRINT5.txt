PASSO 1 — CONFIGURAR SUPABASE (IMPORTANTE!)
─────────────────────────────────────────────
Pra cadastro automático funcionar, tem que DESATIVAR a 
confirmação por email (senão o funcionário precisa clicar 
no link do email pra logar).

1. Abre o Supabase
2. Menu da esquerda → Authentication → Providers
3. Clica em "Email"
4. Procura "Confirm email" e DESLIGA (deixa OFF)
5. Salva

(Em produção tu pode ligar isso de novo, mas pra testar fica 
mais fácil sem confirmação)


PASSO 2 — SUBIR A NOVA VERSÃO
─────────────────────────────
A) PARA TESTAR LOCAL:
   1. Apaga pasta vetroline antiga
   2. Extrai vetroline-sprint5.zip
   3. Renomeia "vetroline-v5" pra "vetroline"
   4. Open with Live Server

B) PARA ATUALIZAR NO GITHUB:
   1. Vai no GitHub → teu repositório vetro-line
   2. Clica em "Add file" → "Upload files"
   3. Arrasta TODOS arquivos de dentro da pasta vetroline-v5
   4. Confirma "Replace existing files" se aparecer
   5. Commit changes
