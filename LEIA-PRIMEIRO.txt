Esse é o teu sistema VetroLine completo, pronto pra rodar.

PASSO 1 — ABRIR NO VS CODE
──────────────────────────
1. Extrai esse zip numa pasta (ex: C:\Projetos\vetroline)
2. Abre o VS Code
3. Vai em "File" → "Open Folder"
4. Escolhe a pasta vetroline


PASSO 2 — CRIAR O BANCO DE DADOS (5 minutos)
─────────────────────────────────────────────
1. Abre supabase.com no navegador, faz login
2. Entra no teu projeto VetroLine
3. No menu da esquerda, clica em "SQL Editor"
4. Clica em "New query"
5. No VS Code, abre o arquivo: database/schema.sql
6. Copia TUDO (Ctrl+A → Ctrl+C)
7. Cola no SQL Editor do Supabase (Ctrl+V)
8. Clica em "Run" (botão verde no canto)

⚠️ ATENÇÃO: se tu já tinha rodado o SQL antes, esse vai
APAGAR e recriar tudo. Vai precisar refazer o passo 3.
